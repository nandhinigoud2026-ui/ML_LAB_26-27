CROP RECOMMENDATION ML MINI PROJECT

Files:
1. Crop_Recommendation_ML_Project.ipynb - Jupyter/Google Colab notebook
2. crop_recommendation_dataset.csv - The single dataset used
3. Project_Explanation_and_Viva.txt - Project explanation and viva questions

Run in Google Colab:
1. Open Google Colab and upload the .ipynb notebook.
2. In the left Files panel, upload crop_recommendation_dataset.csv.
3. Run all notebook cells from top to bottom.

Requirements:
Python 3, pandas, numpy, matplotlib, scikit-learn.
The notebook imports the required libraries.

Dataset note:
The CSV contains synthetic educational sample data, not real farm measurements.
